# Human Activity Recognition using LSTM

This project implements a deep learning model using LSTM to classify human activities based on smartphone sensor data.

## Dataset
UCI HAR Dataset (Accelerometer + Gyroscope signals)

## Model
- LSTM-based sequence classifier
- Input shape: (128 timesteps, 6 features)

## Activities
- Walking
- Sitting
- Standing
- Laying
- Upstairs
- Downstairs

## Tech Stack
- Python
- PyTorch
- NumPy
- Scikit-learn

## Training
- Early stopping used
- Cross entropy loss
- Adam optimizer
